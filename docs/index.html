中國抗議蕭美琴訪義，義大利副總理兼外長塔加尼：與北京「沒有任何聯繫」，遵行一中政策但支持維持現狀 — 中央社 9/13 00:32 報導，蕭美琴副總統出席義大利文托泰內島（Ventotene）「歐洲自由與民主論壇」並演說後，中國外交部稱已就「台獨政客」與會向義方、歐方提出嚴正交涉；義大利副總理兼外長塔加尼（Antonio Tajani）表示此事與北京「沒有任何聯繫」，義國遵行一中政策，同時支持維持區域現狀。歐盟亦表態願與台灣交流，歐洲議會副議長皮齊耶諾盼訪台延續合作。北京的抗議沒有換到歐方讓步，台歐關係持續升溫。
